# 보고서에 남은 부분 코드

본인의 15주차 결과 보고서 Listing 1·3에서 복원했습니다. 전체 원본 모듈·애플리케이션이 없어 `.inc` 파일로 보관합니다. 학번으로 만들었던 표시 값은 일반 예제로 바꿨습니다. 그대로 컴파일하거나 보드를 구동할 수 있는 완성 프로젝트는 아닙니다.

LED 로직은 50,000,000 clock마다 다음 byte를 선택합니다. 보고서의 2초 주기는 25 MHz 입력을 전제로 하며, 파일 자체에는 클럭 생성과 reset 초기화가 없습니다. C 조각은 기존 장치 FD와 변수 선언이 필요합니다. 드라이버의 MMIO 접근과 하드웨어 register 폭·endian까지 검증한 자료는 아닙니다.

2026-10-25에 LearnUs의 2·3·4·5·6·7·9·10·11·13·15주차 결과 보고서를 확인했습니다. 많은 항목은 설명·일부 코드·화면 캡처만 남아 있어 완전한 HDL/C 원본을 재구성하지 않았습니다. 다른 학생의 보관 자료와 수정 이력이 확인되지 않은 수업 배포본은 본인 구현으로 추가하지 않았습니다. 최종 프로젝트 제출 영역에는 첨부파일이 없었습니다.
